# OpenAI 授权连接与质量调度

授权保存在 OpenAI OAuth 母账号下。账号编辑页的 **OpenAI 授权连接** 提供 SIWC 和 Excel/BPS 的浏览器授权入口。打开授权页，选择目标用户和工作区，再将完整回调 URL 粘贴回编辑页。绑定完成后可以启用该连接，也可以切回 Codex。每个账号可同时保存一条 SIWC 和一条 Excel 授权，另有账号原来的 Codex 凭据。

SIWC 和 Excel 的授权会话在共享 Redis 保存 30 分钟。服务校验 OAuth state 和 PKCE，核验签名 ID token 和当前账号身份。Excel 授权还检查授权响应中的工作区与本地账号一致。SIWC 的工作区以用户在首次授权页选定的结果为准，本地使用账号工作区快照约束后续授权和刷新。解除本地绑定会清除本服务保存的凭据，用户侧的授权管理由 OpenAI 提供。

- **SIWC** · HTTP/SSE 到官方 Responses 端点。支持 Responses、Chat Completions 和 Messages。出站重建请求头，对话历史由客户端显式提供。
- **Excel/BPS** · 独立授权访问 Basispoints。支持 Responses、Chat Completions、工具选择、结构化输出和按账号开启的网页搜索。内嵌图片经校验后上传到 BPS 附件端点。图片入口支持满足 BPS 字段约束的非流式 GPT Image 2 生成及单图编辑。按模型配置范围时，范围外的请求在发送前走 Codex。启用该账号的 Excel 授权后，使用 HTTP 请求入口。
- **定时质量检查** · 在账号定时测试中设置问题和期望答案。仅对完整成功且有正文的回答判题，去掉首尾空白后做精确匹配。可启用质量结果参与 OpenAI 高级调度。按账号与模型聚合最近 24 小时的有效结果，每个计划取最近 8 次，至少 3 次有效结果后参与评分。高级调度还使用自身的实时资格检查、并发、延迟和错误率。配置变更会使旧版本的判题结果退出评分。可按连续错答次数隔离该账号的指定模型，有效复测通过后解除质量隔离。

迁移 255 保存加密授权，迁移 256 增加判题配置和结果。数据库备份应保留既有凭据加密密钥。普通账号 API 和导出只包含账号自身的数据，新增授权连接通过管理员接口管理。切回 Codex 或关闭质量评分后，已有授权与判题历史可保留。

SIWC 和 Excel 协议适配参考 Ranxi production 的 [e90811e](https://github.com/Cd1s/sub2api-ranxi/commit/e90811e27bc442763a496027f935a7bb1fb4396b)。Basispoints 源码附带原始归属说明。此移植采用当前 fork 的账号、代理和调度机制。Ranxi 的通用授权记录池、密码/TOTP 自动重登、质量模板、跨分组自动处置和完整性能控制台属于后续移植范围。
